# Live2D Cubism SDK Core Placement (Excluded from Git)

Place the official closed-source Live2D Cubism SDK artifacts here before building with Android Studio:
- `Live2DCubismCore.jar`
- `arm64-v8a/libLive2DCubismCore.so` (if linking JNI natively)

All binaries in this folder are ignored by `.gitignore` to keep the repository MIT-clean.
